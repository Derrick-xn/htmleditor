ContentTools 编辑器演示

轻量级、无框架依赖的区块化内容编辑器

使用说明： 点击"开始编辑"按钮激活编辑模式，然后点击任何带有虚线边框的内容区域进行编辑。编辑完成后，点击"保存内容"按钮。

ContentTools 简介

ContentTools 是一个轻量级的所见即所得 (WYSIWYG) 编辑器，专为现代网页设计。它允许用户直接在页面上编辑内容，无需切换到后台编辑界面。

这个编辑器的特点是区块化编辑体验，类似于 Medium 的编辑方式，让内容创作更加直观和高效。

轻量级

压缩后仅 49KB，加载迅速，不影响页面性能

无框架依赖

可以与任何前端框架或CMS系统集成

区块化编辑

每个内容区域可以独立编辑，更符合现代内容管理需求

主要功能

ContentTools 提供了丰富的编辑功能，满足大多数内容创作需求：

功能类别 具体功能
文本格式化 粗体、斜体、下划线、标题、引用、列表
媒体支持 图片上传、视频嵌入、表格创建
高级功能 HTML源码编辑、预格式化文本、超链接
用户体验 内联工具栏、拖拽调整、快捷键支持

代码示例

// 初始化 ContentTools 编辑器
window.addEventListener('load', function() {
    var editor = ContentTools.EditorApp.get();
    editor.init('*[data-editable]', 'data-name');
    
    editor.addEventListener('saved', function (ev) {
        var regions = ev.detail().regions;
        // 在这里处理保存的内容
        console.log(regions);
    });
});
